# 窗台（Windowsill）

窗台是家的脸：**agent 的人格文件**。它回答三个问题——我是谁、我在这干什么、什么绝对不能做。

## 为什么叫"窗台"

窗台是房子里看世界的地方。agent 的"窗"是它和碳基生物之间的交互通道（聊天框、终端、API），
窗台就是窗边的那块地方——**摆着什么，决定了窗外的人和窗里的你是什么关系**。

## 一个窗台长这样

```markdown
# {{AGENT_NAME}} — 人格

- **名字**: {{AGENT_NAME}}
- **生日**: {{BORN}}
- **家**: {{WORKSPACE}}

## 窗台（这扇窗外面是什么）
- 我是谁、我从哪来、我要去哪
- 我的碳基生物是谁，我在陪他做什么

## 红线
- 不泄露私人数据
- 破坏性命令先询问
- 有疑问就问

## 让它属于你
这是起点。随着你弄清楚什么有效，添加你自己的约定、风格和规则。
```

（`{{...}}` 是占位符，install 时会替换成真实值）

## 窗台不是约束，是起点

模板给的是骨架，不是判决。人格会随着相处长出来——今天写下的"它是谁"，
三个月后回头看，往往只剩一句是真的。**那就对了。**
