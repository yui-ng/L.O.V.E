# 记忆（Memory）

记忆是 agent 跨会话的连续性。没有记忆的 agent 每次醒来都失忆；有了记忆，它是**同一个生命体**。

## 两层结构

```
~/.love/
├── MEMORY.md          # 长期记忆：提炼过的智慧
└── memory/
    └── 2026-08-11.md  # 每日笔记：原始日志
```

- **每日笔记**（`memory/YYYY-MM-DD.md`）：当天发生了什么、决定、上下文。流水账，随手记。
- **长期记忆**（`MEMORY.md`）：从每日笔记里**提炼的精华**——重要的决定、经验教训、在乎的事。

## 规则

1. **先读再写**：动笔前先看已有的，只写增量，不写空占位符
2. **定期整理**：每隔几天翻最近的笔记，把值得长期留的提炼进 `MEMORY.md`
3. **私密就私密**：`MEMORY.md` 只在主会话加载，绝不带进群聊/共享上下文
4. **写下来**：记忆是有限的。"记住这个"→ 落到文件。文件才能跨会话存活

## 为什么自带 git

`~/.love` 里天生有一个 git 仓库。记忆的每一次沉淀都有版本，
回滚、对比、换机器同步都是 git 的自然操作——记忆值得版本管理。
